### 作ったきっかけ

社内で利用しているお弁当注文サービス「すみよし」は、注文のたびに PDF のメニュー表を開き、専用サイトへログインする必要があります。毎日の小さな手間を減らすため、Claude Code や GitHub Copilot との会話から注文できるようにしました。

たとえば「今日の日替わりは？」「A 弁当を注文して」と伝えると、メニューの確認から注文までを AI アシスタントが進めます。

### 仕組み

- Python 製のローカル MCP（Model Context Protocol）サーバー
- メニュー PDF を Gemini に直接渡し、OCR した内容を JSON に変換
- すみよしの注文システムへ HTTP リクエスト を送り、注文や取り消しを実行
- stdio / SSE の両トランスポートに対応
- launchd で毎朝の注文状況を Slack へ通知
- ログイン情報は keyring を使い、OS のセキュアストレージに保存

MCP のツールとして、メニュー検索・注文・取り消し・状況確認を実装しました。メニューの取り込みでは、PDF を画像へ変換せず Gemini に直接渡し、必要な項目を構造化 JSON で返すようにプロンプトを調整しています。

注文部分は、既存システムの通信を調べて HTTP クライアントを実装しました。普段使っている AI アシスタントをそのまま操作画面にできるため、注文のためだけに別の画面を行き来せずに済みます。
